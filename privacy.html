바탕화면달력 개인정보 처리 안내

바탕화면달력(PC 프로그램과 휴대폰 앱)은 개인이 만든 무료 일정 달력입니다.

저장하는 정보와 장소

입력한 일정, 사용자 이름, 달력 설정(색·글꼴·배경 사진·기념일)은 사용자 본인의 구글 드라이브 안, 이 앱만 쓰는 숨은 폴더(앱 데이터 폴더)와 사용자의 PC·휴대폰에만 저장됩니다. 만든 사람의 서버나 다른 곳으로는 보내지 않으며, 만든 사람도 볼 수 없습니다.

요청하는 구글 권한

· 구글 드라이브 앱 데이터 폴더 읽기·쓰기 (drive.appdata): 일정을 저장하고 PC·휴대폰끼리 맞추기 위해 씁니다. 사용자의 다른 드라이브 파일은 볼 수 없습니다.
· 이메일 주소 (email): 어느 계정으로 로그인했는지 화면에 보여 주기 위해서만 씁니다.

삭제

구글 계정 → 보안 → 타사 앱 연결에서 "바탕화면달력" 접근을 없애거나, 구글 드라이브 설정 → 앱 관리에서 "바탕화면달력"의 숨은 앱 데이터를 삭제할 수 있습니다.
